## 命名原则

- 文件名前面的 `01、02、03...` 表示建议学习顺序。
- 文件名直接写主要知识点，不再使用 `test01.py` 这类无法辨认内容的名称。
- Python 关键字、库名和 API 名称，例如 `async`、`await`、`Pydantic`、`BeforeValidator`，保留英文，方便和真实代码对应。
- `pyproject.toml`、`uv.lock`、`.python-version` 属于项目标准配置文件，因此不改成中文名。
