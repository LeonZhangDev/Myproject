1. **Obsidian 只能方便地打开 Windows 路径**，所以把真实目录放在：

```
C:\Users\Administrator\Desktop\project
```

然后让 WSL 的：

```
/home/damon/project
```

通过符号链接指向：

```
/mnt/c/Users/Administrator/Desktop/project
```

这样 Windows 和 WSL 用的是**同一份文件**，不是两份同步副本。

2. 一开始 `rsync` 报：

```
Input/output error
```

原因是 Windows 桌面的 `project` 当时还是一个错误的符号链接。解决方法是先删掉 Windows 链接，重新创建真正的 `project` 文件夹，再复制文件。

3. 后来 `git push` 报：

```
fetch first
non-fast-forward
```

说明 GitHub 远程 `main` 有你本地没有的新提交，所以不能直接 push，需要先：

```
git pull --rebase origin main
```

4. 但 rebase 时本地有大量 Obsidian/Windows 修改，Git 不允许覆盖，于是 rebase 卡住。期间 `git stash pop` 也因为本地修改冲突而失败。
5. 最后发现 Git 处于：

```
interactive rebase in progress
```

而且同一个提交：

```
c61a3d9 更新
```

被重复排进 rebase，所以先把当前修改并入提交：

```
git add .
git commit --amend --no-edit
```

然后：

```
git rebase --edit-todo
```

把：

```
pick c61a3d9 更新
```

改成：

```
drop c61a3d9 更新
```

Nano 中保存退出：

```
Ctrl + O
Enter
Ctrl + X
```

最后：

```
git rebase --continue
git status
git push origin main
```
