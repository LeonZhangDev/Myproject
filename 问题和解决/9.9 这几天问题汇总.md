| 类别          | 你遇到的问题                                                               | 本质                        | 应该怎么处理                                             |     |
| ----------- | -------------------------------------------------------------------- | ------------------------- | -------------------------------------------------- | --- |
| Docker      | `make up` 构建、拉取镜像时出现问题                                               | Docker 网络/构建上下文/镜像源       | 分清是 `pull` 失败、`build` 失败还是容器启动失败                   |     |
| RAG         | 不清楚 LlamaIndex、FAISS、BGE-M3、LangGraph 分工                             | 框架层级混淆                    | 固定 MindTrip 当前技术栈，不再混着理解                           |     |
| Query       | Query Rewrite、Standalone Query、Query Decomposer、Multi-Query、HyDE 不清楚 | Query Processing 没形成体系    | 按“改写 / 拆分 / 扩展 / 假答案”四类记                           |     |
| Retrieval   | Dense、Sparse、Hybrid、RRF、过滤、召回概念混淆                                    | 检索 pipeline 没串起来          | 用一条完整 Retrieval Pipeline 理解                        |     |
| 来源引用        | 模型怎么像 ChatGPT 一样生成 `[1][2]` 来源链接                                     | 生成与证据绑定混淆                 | Retrieval → Answer → Claim → Citation Verification |     |
| Claim       | Atomic Claim、Citation Binding、Claim Verification 是否需要独立模型            | Verification pipeline 不清楚 | 拆成生成模型 + 验证模型两类职责                                  |     |
| Transformer | QKV、多头、GQA/MQA、Pre-Norm、Post-Norm、Mask                               | 基础模型结构在补课                 | 不要散着背，围绕一个 Transformer Block 学                     |     |
| 数学基础        | LayerNorm、RMSNorm、GELU、Temperature、Sigmoid                           | 公式有印象但计算过程不牢              | 每个公式自己手算一个极小例子                                     |     |
| 检索指标        | MRR、NDCG、Precision@K、Recall@K、Hit Rate                               | 指标名字多、区别容易混               | 按“有没有找到 / 排得好不好”分类                                 |     |
| 工程架构        | FastAPI Router、Schema、Service、Repository 各负责什么                       | 分层职责还没完全固化                | 按 HTTP → 校验 → 业务 → DB 的调用链记                        |     |
| PostgreSQL  | Session、事务、索引、Join、`expire_on_commit`                                | ORM 生命周期理解                | 从“一次请求”视角学习                                        |     |
| Redis       | Cache-Aside、TTL、空值缓存                                                 | 缓存设计刚接触                   | 先掌握 Get → Redis → DB → 回填                          |     |
| 项目表达        | MindTrip 到底现在用了哪些技术                                                  | 历史版本太多                    | 只维护一个“当前实现基线”                                      |     |
