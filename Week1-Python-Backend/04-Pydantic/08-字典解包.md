# 字典解包

## 一句话理解

`**dict` 展开成关键字参数。

## 核心理解

常与 `model_dump()` 往返使用。

## 最小代码 / 场景

```python
data={'title':'A'}
task=TaskCreate(**data)
```


## 🧪 简单例子与返回结果

### 例子

```python
from pydantic import BaseModel

class User(BaseModel):
    id: int
    name: str

data = {"id": 1, "name": "Leon"}
u = User(**data)
print(u)
```

### 运行 / 返回结果

```text
id=1 name='Leon'
```
