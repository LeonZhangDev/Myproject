# 嵌套模型

## 一句话理解

BaseModel 字段可以继续是 BaseModel。

## 核心理解

适合结构化 JSON、复杂响应。

## 最小代码 / 场景

```python
class Task(BaseModel):
    owner:User
```


## 🧪 简单例子与返回结果

### 例子

```python
from pydantic import BaseModel

class Address(BaseModel):
    city: str

class User(BaseModel):
    name: str
    address: Address

u = User(name="Leon", address={"city": "Chengdu"})
print(u.address.city)
```

### 运行 / 返回结果

```text
Chengdu
```
