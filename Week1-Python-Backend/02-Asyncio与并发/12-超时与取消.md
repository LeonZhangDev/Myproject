# 异步超时与取消

## 一句话理解

所有外部 I/O 都应有超时边界，取消要正确清理资源。

## 核心理解

取消触发 `CancelledError`；清理放 finally，通常不要吞掉取消。

## 最小代码 / 场景

```python
async with asyncio.timeout(2):
    await remote_call()
```


## 🧪 简单例子与返回结果

### 例子

```python
import asyncio

async def slow():
    await asyncio.sleep(2)

async def main():
    try:
        await asyncio.wait_for(slow(), timeout=0.1)
    except asyncio.TimeoutError:
        print("timeout")

asyncio.run(main())
```

### 运行 / 返回结果

```text
timeout
```
