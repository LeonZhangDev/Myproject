# 并发与并行

## 一句话理解

并发是多个任务交替推进；并行是同一时刻真正同时执行。

## 核心理解

I/O 密集常需要高并发；CPU 密集更关心多核并行。

## 最小代码 / 场景

```text
并发: A -> B -> A
并行: Core1:A | Core2:B
```


## 🧪 简单例子与返回结果

### 例子

```python
import asyncio

async def job(name):
    print(name, "开始")
    await asyncio.sleep(0.1)
    print(name, "结束")

async def main():
    await asyncio.gather(job("A"), job("B"))

asyncio.run(main())
```

### 运行 / 返回结果

```text
A 开始
B 开始
A 结束
B 结束
```

**怎么理解：** 这里展示的是并发：A 等待 I/O 时，事件循环可以去运行 B。
