# 阻塞调用

## 一句话理解

阻塞调用占住当前线程；放在事件循环线程会拖慢其他协程。

## 核心理解

优先异步库；无法替换的阻塞 I/O 可 `asyncio.to_thread`；CPU 重任务用进程池/独立服务。

## 最小代码 / 场景

```python
# bad
time.sleep(5)
# better async wait
await asyncio.sleep(5)
```


## 🧪 简单例子与返回结果

### 例子

```python
import asyncio, time

async def bad():
    print("A start")
    time.sleep(0.2)       # 阻塞整个事件循环
    print("A end")

async def other():
    print("B run")

async def main():
    await asyncio.gather(bad(), other())

asyncio.run(main())
```

### 运行 / 返回结果

```text
A start
A end
B run
```

**怎么理解：** 因为 time.sleep 是阻塞调用，B 不能在 A 睡眠期间运行。I/O 异步代码里应优先使用 await asyncio.sleep(...) 或线程池包装阻塞库。
