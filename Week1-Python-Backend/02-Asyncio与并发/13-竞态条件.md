# 竞态条件

## 一句话理解

单线程协程也会因为 await 交错执行而破坏共享状态。

## 核心理解

如果“读→改→写”之间存在 await，其他协程可能插进来。

## 最小代码 / 场景

```python
tmp=count
await asyncio.sleep(0)
count=tmp+1
```
