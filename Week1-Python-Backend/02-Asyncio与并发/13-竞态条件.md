# 竞态条件

## 一句话理解

单线程协程也会因为 await 交错执行而破坏共享状态。

## 核心理解

如果“读→改→写”之间存在 await，其他协程可能插进来。

## 最小代码 / 场景

```python
tmp=count
await asyncio.sleep(0)
count=tmp+1
```


## 🧪 简单例子与返回结果

### 例子

```python
import asyncio

counter = 0
async def add_one():
    global counter
    old = counter
    await asyncio.sleep(0)
    counter = old + 1

async def main():
    await asyncio.gather(*(add_one() for _ in range(100)))
    print(counter)

asyncio.run(main())
```

### 运行 / 返回结果

```text
1
```

**怎么理解：** 100 个协程都可能先读到同一个旧值，再覆盖彼此结果，这就是竞态条件。
