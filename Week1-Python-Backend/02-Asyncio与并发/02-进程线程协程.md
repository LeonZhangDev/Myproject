# 进程、线程、协程

## 一句话理解

进程隔离强，线程由 OS 调度，协程由事件循环协作调度。

## 核心理解

协程不是线程，也不会因为 async 自动利用多核。

## 最小代码 / 场景

```text
进程: 独立内存
线程: 共享进程内存
协程: 单线程内协作切换
```


## 🧪 简单例子与返回结果

### 例子

```python
import asyncio

async def fetch(i):
    await asyncio.sleep(0.1)
    return f"task-{i}"

async def main():
    print(await asyncio.gather(fetch(1), fetch(2)))

asyncio.run(main())
```

### 运行 / 返回结果

```text
['task-1', 'task-2']
```

**怎么理解：** 协程适合大量 I/O；线程常用于阻塞 I/O；CPU 密集任务通常考虑多进程。
