# 数据库测试隔离

## 一句话理解

每个测试要有独立数据边界。

## 核心理解

可每用例事务 rollback、临时 DB/schema、唯一数据；不要并发测试共享全局 Session。

## 最小代码 / 场景

```python
@pytest.fixture
async def db():
    async with TestSession() as s:
        yield s
        await s.rollback()
```
