# 数据库测试隔离

## 一句话理解

每个测试要有独立数据边界。

## 核心理解

可每用例事务 rollback、临时 DB/schema、唯一数据；不要并发测试共享全局 Session。

## 最小代码 / 场景

```python
@pytest.fixture
async def db():
    async with TestSession() as s:
        yield s
        await s.rollback()
```


## 🧪 简单例子与返回结果

### 例子

```text
test_create_user 开始 -> 开启事务
测试中 INSERT user
断言通过 -> ROLLBACK
```

### 运行 / 返回结果

```text
测试内能查到新 user；
测试结束 rollback 后，数据库恢复到测试前状态，不污染下一条测试。
```
