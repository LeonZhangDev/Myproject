# 参数化测试

## 一句话理解

一份测试逻辑覆盖多组输入边界。

## 核心理解

减少重复测试代码。

## 最小代码 / 场景

```python
@pytest.mark.parametrize('x,ok',[(1,True),(0,False)])
```


## 🧪 简单例子与返回结果

### 例子

```python
import pytest

@pytest.mark.parametrize("a,b,result", [
    (1, 2, 3),
    (2, 3, 5),
    (10, 20, 30),
])
def test_add(a, b, result):
    assert a + b == result
```

### 运行 / 返回结果

```text
$ pytest -q
3 passed
```

**怎么理解：** 同一个测试逻辑自动跑三组参数。
