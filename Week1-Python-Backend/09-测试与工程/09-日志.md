# 日志

## 一句话理解

日志是问题发生后还原行为的证据。

## 核心理解

至少要有时间、级别、request_id、路径、耗时、错误。

## 最小代码 / 场景

```text
2026-... INFO request_id=... path=/tasks duration_ms=34
```


## 🧪 简单例子与返回结果

### 例子

```python
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)
logger.info("user_id=%s login success", 42)
```

### 运行 / 返回结果

```text
INFO:__main__:user_id=42 login success
```
