# 集成测试

## 一句话理解

验证 API、DB、Redis 等真实协作。

## 核心理解

关键接口、事务和缓存行为应有集成测试。

## 最小代码 / 场景

```text
HTTP -> FastAPI -> SQLAlchemy -> Test DB
```


## 🧪 简单例子与返回结果

### 例子

```python
from fastapi.testclient import TestClient

client = TestClient(app)

def test_ping():
    r = client.get("/ping")
    assert r.status_code == 200
    assert r.json() == {"pong": True}
```

### 运行 / 返回结果

```text
pytest 运行：
1 passed
```

**怎么理解：** 这里同时经过了 FastAPI 路由、请求处理和响应序列化，比只测一个普通函数更接近集成测试。
