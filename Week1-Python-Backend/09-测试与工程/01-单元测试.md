# 单元测试

## 一句话理解

隔离一个函数/服务/工具，快且定位精确。

## 核心理解

适合纯业务逻辑、校验、工具函数。

## 最小代码 / 场景

```python
def test_add(): assert add(1,2)==3
```


## 🧪 简单例子与返回结果

### 例子

```python
def add(a, b):
    return a + b

def test_add():
    assert add(2, 3) == 5
```

### 运行 / 返回结果

```text
pytest 运行：
1 passed
```
