# 请求完整数据流
```text
Client -> Middleware(request_id) -> Route -> Depends(get_session) -> Pydantic
-> Redis GET -> miss -> SQLAlchemy -> PostgreSQL -> response model -> Redis SET -> Client
```

异常：业务/数据库异常 → AppException → 全局 handler → 统一 JSON。
