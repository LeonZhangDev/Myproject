# 文件上传

## 一句话理解

`UploadFile` 处理 multipart 文件上传。

## 核心理解

要校验类型/大小/文件名；大文件避免一次性全读内存。

## 最小代码 / 场景

```python
async def upload(file:UploadFile):
    content=await file.read()
```


## 🧪 简单例子与返回结果

### 例子

```python
from fastapi import FastAPI, UploadFile
app = FastAPI()

@app.post("/upload")
async def upload(file: UploadFile):
    return {"filename": file.filename}
```

### 运行 / 返回结果

```text
上传文件 avatar.png
200 OK
{"filename":"avatar.png"}
```
