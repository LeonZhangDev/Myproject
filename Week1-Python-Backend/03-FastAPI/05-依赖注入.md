# FastAPI 依赖注入

## 一句话理解

把 Session、认证、配置、公共校验从路由拆出去。

## 核心理解

价值：复用、测试替换、资源清理、接口声明清楚。

## 最小代码 / 场景

```python
async def route(session=Depends(get_session)):
    ...
```


## 🧪 简单例子与返回结果

### 例子

```python
from fastapi import Depends, FastAPI
app = FastAPI()

def get_current_user():
    return "Leon"

@app.get("/me")
def me(user: str = Depends(get_current_user)):
    return {"user": user}
```

### 运行 / 返回结果

```text
GET /me
200 OK
{"user":"Leon"}
```
