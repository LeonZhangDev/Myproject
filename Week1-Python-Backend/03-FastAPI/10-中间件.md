# FastAPI 中间件

## 一句话理解

中间件包住几乎所有请求，适合全局横切逻辑。

## 核心理解

典型：request_id、统一耗时、日志、CORS。

## 最小代码 / 场景

```python
@app.middleware('http')
async def mw(request, call_next):
    response=await call_next(request); return response
```


## 🧪 简单例子与返回结果

### 例子

```python
from fastapi import FastAPI, Request
app = FastAPI()

@app.middleware("http")
async def add_header(request: Request, call_next):
    response = await call_next(request)
    response.headers["X-App"] = "demo"
    return response

@app.get("/")
def home():
    return {"ok": True}
```

### 运行 / 返回结果

```text
GET /
200 OK
X-App: demo
{"ok":true}
```
