# FastAPI 中间件

## 一句话理解

中间件包住几乎所有请求，适合全局横切逻辑。

## 核心理解

典型：request_id、统一耗时、日志、CORS。

## 最小代码 / 场景

```python
@app.middleware('http')
async def mw(request, call_next):
    response=await call_next(request); return response
```
