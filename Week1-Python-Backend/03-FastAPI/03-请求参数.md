# 请求参数

## 一句话理解

FastAPI 根据参数位置和类型注解解析 path/query/header/body。

## 核心理解

类型声明同时帮助校验和 OpenAPI。

## 最小代码 / 场景

```python
async def get_task(task_id:int, limit:int=10): ...
```


## 🧪 简单例子与返回结果

### 例子

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/search")
def search(q: str, limit: int = 10):
    return {"q": q, "limit": limit}
```

### 运行 / 返回结果

```text
GET /search?q=python&limit=3
200 OK
{"q":"python","limit":3}
```
