# 索引选择性

## 一句话理解

条件越能把数据缩小到很小范围，选择性通常越高。

## 核心理解

email 几乎唯一，选择性高；二值状态列常选择性低。

## 最小代码 / 场景

```text
1,000,000 rows -> email match 1 row: high selectivity
```


## 🧪 简单例子与返回结果

### 例子

```text
列 A：gender 只有 2 个值 -> 选择性低
列 B：email 几乎每行都不同 -> 选择性高
```

### 运行 / 返回结果

```text
通常 email 更适合普通 B-Tree 索引定位单条记录；
gender 单列索引在很多查询里收益较小。
```
