# ORM N+1

## 一句话理解

先查 N 条主记录，再为每条关联数据额外查一次，形成 1+N 查询。

## 核心理解

通过 SQL 日志/查询计数发现；用 selectinload/joinedload/JOIN/批量查询解决。

## 最小代码 / 场景

```python
stmt=select(User).options(selectinload(User.tasks))
```
