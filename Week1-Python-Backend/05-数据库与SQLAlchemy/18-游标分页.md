# 游标分页

## 一句话理解

按稳定唯一排序键继续查询。

## 核心理解

深分页性能和一致性更好，但不方便任意跳页。

## 最小代码 / 场景

```sql
SELECT * FROM tasks WHERE id<:last_id ORDER BY id DESC LIMIT 20;
```


## 🧪 简单例子与返回结果

### 例子

```sql
SELECT id, title
FROM tasks
WHERE id > 20
ORDER BY id
LIMIT 10;
```

### 运行 / 返回结果

```text
如果上一页最后一个 id=20：
返回 id > 20 的下一批最多 10 条记录。
```
