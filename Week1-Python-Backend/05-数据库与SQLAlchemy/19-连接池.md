# 连接池

## 一句话理解

复用数据库连接，避免每请求都重新建立连接。

## 核心理解

耗尽常见原因：Session 泄漏、长事务、慢 SQL、占着连接调外部 API、流量突增、池太小。

## 最小代码 / 场景

```text
request -> pool wait -> active conn -> SQL -> release
```


## 🧪 简单例子与返回结果

### 例子

```text
pool_size = 5
同时来了 8 个需要数据库连接的请求
```

### 运行 / 返回结果

```text
最多 5 个请求先获得池内连接；
其余请求等待连接被归还（或达到超时后失败）。
```
