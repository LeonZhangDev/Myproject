# 缓存一致性

## 一句话理解

缓存是数据库副本，更新不同步就会读旧数据。

## 核心理解

常见：Cache-Aside、写后失效、TTL、版本号、消息/CDC、删除失败重试。

## 最小代码 / 场景

```text
UPDATE DB -> COMMIT -> DELETE CACHE
```


## 🧪 简单例子与返回结果

### 例子

```text
更新用户昵称：
1. UPDATE users SET name='Leon' WHERE id=1
2. DEL user:1
```

### 运行 / 返回结果

```text
下一次读取 user:1：缓存 miss
-> 重新查数据库得到 Leon
-> 写回最新缓存
```

**怎么理解：** 常见 Cache-Aside 更新策略是“先更新数据库，再删除缓存”。
