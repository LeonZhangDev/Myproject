# 内存淘汰策略

## 一句话理解

Redis 达到内存上限时决定淘汰哪些 Key。

## 核心理解

TTL 是时间规则；淘汰是内存压力规则。

## 最小代码 / 场景

```text
TTL: when expire
Eviction: who to remove when memory full
```


## 🧪 简单例子与返回结果

### 例子

```text
maxmemory 已满
策略：allkeys-lru
```

### 运行 / 返回结果

```text
Redis 会从所有 key 中优先淘汰较久未使用的 key，为新写入腾出空间。
```
