# 缓存穿透

## 一句话理解

反复查询不存在数据，缓存永远 miss，压力打到 DB。

## 核心理解

参数校验、空值短缓存、布隆过滤器。

## 最小代码 / 场景

```python
if obj is None: await redis.set(key,'__NULL__',ex=30)
```


## 🧪 简单例子与返回结果

### 例子

```python
def get_user(user_id):
    key = f"user:{user_id}"
    cached = r.get(key)
    if cached == "__NULL__":
        return None

    user = query_database(user_id)
    if user is None:
        r.set(key, "__NULL__", ex=60)
        return None
    return user
```

### 运行 / 返回结果

```text
第一次查询不存在的 user:999：查 DB，写入 __NULL__
第二次查询 user:999：Redis 命中 __NULL__，直接返回 None
DB 不再被重复打。
```
