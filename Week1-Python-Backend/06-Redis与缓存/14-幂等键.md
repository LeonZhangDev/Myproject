# 幂等键

## 一句话理解

识别重复请求，让重复提交不重复产生副作用。

## 核心理解

关键唯一性仍要数据库约束兜底。

## 最小代码 / 场景

```redis
SET idem:order:abc 1 NX EX 300
```


## 🧪 简单例子与返回结果

### 例子

```text
请求携带 Idempotency-Key: order-abc
服务先执行 SET order-abc processing NX EX 60
```

### 运行 / 返回结果

```text
第一次请求：SET 成功 -> 创建订单
重复请求：SET 失败 -> 不再重复创建订单
```
