# Redis 分布式锁

## 一句话理解

协调多个进程/机器对同一资源的互斥访问。

## 核心理解

需要原子加锁、过期、唯一 token、安全释放、长任务续期；不能替代幂等/唯一约束。

## 最小代码 / 场景

```redis
SET lock:task:1 token-abc NX PX 10000
```


## 🧪 简单例子与返回结果

### 例子

```text
服务 A：SET lock:job tokenA NX PX 10000 -> 成功
服务 B：SET lock:job tokenB NX PX 10000 -> 失败
```

### 运行 / 返回结果

```text
A 获得锁并执行临界任务；
B 此时不能同时进入，避免多个实例重复执行同一任务。
```
