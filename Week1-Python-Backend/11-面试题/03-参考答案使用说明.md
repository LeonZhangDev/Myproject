# 参考答案使用说明

本版 W1-Q1～W1-Q40 的参考答案统一改为 **真人口述版**。

建议不要逐字背诵，而是按每题的 `回答逻辑` 记住顺序：

1. 先给结论，直接回答问题；
2. 再解释为什么，体现底层理解；
3. 补真实后端场景或容易踩坑的地方；
4. 最后给边界条件或工程选型，让答案能接住追问。

实际面试时，第一轮控制在 45～90 秒。如果面试官继续追问，再展开下面的最小代码、关联知识和排障思路。

## 这一版参考答案怎么用

这一版不建议逐字背。每题先记住下面四层：

1. **先给结论**：先让面试官知道你站在哪个判断上。
2. **解释原因**：把底层机制讲清楚，不只报术语。
3. **落到工程场景**：说清楚在 FastAPI / SQLAlchemy / Redis 项目里会怎么做。
4. **补边界和坑**：主动说明什么时候这个结论不成立，避免回答得太绝对。

真正口述时可以根据面试官反应收缩到 60~90 秒；如果对方继续追问，再展开后面的工程细节。这样听起来会比整段背稿更自然。
