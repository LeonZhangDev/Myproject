## 使用方法
1. 按 Day 1 → Day 5 学。
2. 每篇先看“一句话理解”，再遮住“运行 / 返回结果”自己预测一次，然后跑代码验证。
3. 遇到 `[[双向链接]]` 顺着跳，建立知识链。
4. 面试题先口述 30~60 秒，再看回答骨架。
5. 最后回到综合项目，把知识串起来。
