# 如何使用这个知识库

## 推荐方式
1. 从 [[00-第一周学习首页]] 开始。
2. 按 [[02-五天学习路线]] 学，不按文件夹死背。
3. 每篇先理解“一句话理解”，再自己运行代码。
4. 学到新概念时查看“关联知识”，用 Obsidian Local Graph 看上下游关系。
5. 每天结束做对应面试题：先口述，再看答案。
6. 最后回到 [[../10-综合项目-ai-service-starter/00-项目说明]]，把知识放进真实请求链。

## 面试题练法
```text
看到问题
  ↓
先讲结论
  ↓
解释原理
  ↓
写最小代码
  ↓
联系 FastAPI 项目
  ↓
补充边界 / 错误 / 排查
```
