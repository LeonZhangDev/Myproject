# 生成器与 yield

## 一句话理解

生成器用 `yield` 简洁地创建惰性迭代器。

## 核心理解

适合大文件、流式数据、SSE token；数据按需生成，不必一次性占满内存。

## 🧠 完整理解

### 我会先这样理解

生成器是创建迭代器的一种非常简洁的方式。函数里只要出现 `yield`，调用函数时不会立刻执行完整函数体，而是先返回生成器对象；每次 `next()` 执行到下一个 yield 就暂停，并把局部变量和执行位置保留下来。下一次继续从暂停点往后跑。它特别适合流式处理和“大量数据但一次只需要一条”的场景。

### 执行顺序 / 思考顺序

调用生成器函数 → 得到 generator 对象 → 第一次 next 才真正进入函数体 → 执行到 yield 返回一个值并冻结现场 → 下一次 next 恢复现场 → return 或走到结尾时触发 StopIteration。

### 容易踩的坑

`yield` 不是普通的 `return`。return 会结束函数；yield 是“产出一个值并暂停”。另外生成器也不是自动并发，它只是惰性迭代机制。

### 面试时我会这样说

> 我一般把 yield 理解成“函数执行到这里先交一个结果出去，但现场别销毁”。所以它很适合读大文件、分页拉取、流式生成。如果只是把全部结果都先算出来再 yield，那就失去很多意义了。

## 最小代码 / 场景

```python
def nums():
    yield 1
    yield 2
for x in nums(): print(x)
```


## 🧪 简单例子与返回结果

### 例子

```python
def numbers():
    yield 1
    yield 2
    yield 3

for x in numbers():
    print(x)
```

### 运行 / 返回结果

```text
1
2
3
```

**怎么理解：** yield 每次只产出一个值，并保留函数当前执行位置。
