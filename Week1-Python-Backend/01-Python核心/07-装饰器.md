# 装饰器

## 一句话理解

装饰器接收函数并返回新的可调用对象。

## 核心理解

常用于日志、鉴权、缓存、重试；FastAPI 的 `@app.get()` 也是装饰器使用。

## 最小代码 / 场景

```python
def log(fn):
    def wrapper(*a,**kw):
        print('call'); return fn(*a,**kw)
    return wrapper
```
