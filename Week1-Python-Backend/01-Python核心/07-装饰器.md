# 装饰器

## 一句话理解

装饰器接收函数并返回新的可调用对象。

## 核心理解

常用于日志、鉴权、缓存、重试；FastAPI 的 `@app.get()` 也是装饰器使用。

## 最小代码 / 场景

```python
def log(fn):
    def wrapper(*a,**kw):
        print('call'); return fn(*a,**kw)
    return wrapper
```


## 🧪 简单例子与返回结果

### 例子

```python
def log_call(func):
    def wrapper(*args, **kwargs):
        print("调用前")
        result = func(*args, **kwargs)
        print("调用后")
        return result
    return wrapper

@log_call
def add(a, b):
    print("执行 add")
    return a + b

print("返回值:", add(2, 3))
```

### 运行 / 返回结果

```text
调用前
执行 add
调用后
返回值: 5
```

**怎么理解：** 可以把它理解成 add = log_call(add)：原函数没有改，但外面多包了一层逻辑。
