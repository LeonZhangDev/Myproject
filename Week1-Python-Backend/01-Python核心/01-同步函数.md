# 同步函数

## 一句话理解

普通 `def` 函数按当前线程顺序运行。

## 核心理解

同步不是“慢”的同义词，只表示调用者会等函数返回后再继续。

## 最小代码 / 场景

```python
import time
def task(n):
    time.sleep(1)
    return n
print(task('A')); print(task('B'))
```


## 🧪 简单例子与返回结果

### 例子

```python
def add(a, b):
    print("开始计算")
    return a + b

result = add(2, 3)
print(result)
```

### 运行 / 返回结果

```text
开始计算
5
```
