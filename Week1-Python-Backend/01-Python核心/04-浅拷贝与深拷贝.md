# 浅拷贝与深拷贝

## 一句话理解

浅拷贝只复制外层；深拷贝递归复制嵌套对象。

## 核心理解

嵌套列表/配置最容易踩“副本修改影响原对象”的坑。

## 最小代码 / 场景

```python
import copy
a=[[1]]; b=copy.copy(a); c=copy.deepcopy(a)
a[0].append(2); print(b,c)
```


## 🧪 简单例子与返回结果

### 例子

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.copy(a)
c = copy.deepcopy(a)

a[0].append(99)
print(b)
print(c)
```

### 运行 / 返回结果

```text
[[1, 2, 99], [3, 4]]
[[1, 2], [3, 4]]
```

**怎么理解：** 浅拷贝只复制最外层容器；深拷贝连嵌套对象也复制。
