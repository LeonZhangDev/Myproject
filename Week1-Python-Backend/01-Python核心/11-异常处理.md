# 异常处理

## 一句话理解

异常把正常路径与失败路径分开。

## 核心理解

`try/except/finally` 负责捕获与清理；FastAPI 再把业务异常映射成 HTTP 响应。

## 最小代码 / 场景

```python
try: int('x')
except ValueError as e: print(e)
finally: print('cleanup')
```


## 🧪 简单例子与返回结果

### 例子

```python
try:
    x = 10 / 0
except ZeroDivisionError:
    print("不能除以 0")
finally:
    print("清理完成")
```

### 运行 / 返回结果

```text
不能除以 0
清理完成
```
