# 可变默认参数

## 一句话理解

默认参数在函数定义时只创建一次。

## 核心理解

list/dict 作为默认值会被多次调用共享，产生隐藏状态；用 None 再在函数内创建。

## 🧠 完整理解

### 我会先这样理解

函数默认参数是在“定义函数”时计算一次，不是每次调用时重新创建。因此把 `[]`、`{}` 这种可变对象放到默认参数里，相当于让多次调用共享同一个对象。第一次调用 append 的内容，第二次调用还能看到，这往往不是业务想要的行为。标准写法是默认值用 `None`，进入函数后再创建新的容器。

### 执行顺序 / 思考顺序

Python 加载模块并执行 `def` → 创建那个默认 list → 第一次调用复用它并修改 → 第二次调用仍拿到同一个 list。改成 `items=None` 后，每次调用再执行 `items = []`，对象生命周期就变成每次调用独立。

### 容易踩的坑

并不是“可变默认参数永远不能用”，极少数场景可以故意利用它做缓存；但这种写法语义隐蔽，工程代码里通常不值得。

### 面试时我会这样说

> 这题我会先说原因：默认参数不是调用时创建，而是函数定义时就创建了。所以 `def f(x=[])` 里的这个 list 会一直被复用。工程里我基本都写 `None`，然后函数内部初始化，避免跨请求、跨调用串数据。

## 最小代码 / 场景

```python
def add(x, items=None):
    if items is None: items=[]
    items.append(x); return items
```


## 🧪 简单例子与返回结果

### 例子

```python
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("A"))
print(add_item("B"))
```

### 运行 / 返回结果

```text
['A']
['A', 'B']
```

**怎么理解：** 第二次调用复用了第一次的默认 list。更安全的写法是默认值用 None，再在函数内部创建新 list。
