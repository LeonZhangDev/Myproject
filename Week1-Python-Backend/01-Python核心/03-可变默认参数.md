# 可变默认参数

## 一句话理解

默认参数在函数定义时只创建一次。

## 核心理解

list/dict 作为默认值会被多次调用共享，产生隐藏状态；用 None 再在函数内创建。

## 最小代码 / 场景

```python
def add(x, items=None):
    if items is None: items=[]
    items.append(x); return items
```


## 🧪 简单例子与返回结果

### 例子

```python
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("A"))
print(add_item("B"))
```

### 运行 / 返回结果

```text
['A']
['A', 'B']
```

**怎么理解：** 第二次调用复用了第一次的默认 list。更安全的写法是默认值用 None，再在函数内部创建新 list。
